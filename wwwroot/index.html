About

I write C# and ASP.NET Core services, and I like it when a change I push shows up running a few minutes later, with nobody copying files by hand.

This page is a small example. When I push a change to GitHub, an Azure DevOps pipeline builds it on my own agent, a release waits for my approval and my supervisor's, and then the site updates on IIS.

I enjoy turning slow, manual release steps into repeatable ones that a whole team can trust.
